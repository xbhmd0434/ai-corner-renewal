抖音展示 Demo × AI 一角焕新
===========================

当前成熟度
----------

这是一个已经接通 ai-corner-renewal 持久化后端的联调原型，不是生产发布版。
上传图片、空间解析与确认、任务生成、运行轮询、方案历史和方案详情均使用真实 /api/v1 数据。

运行环境
--------

- Node.js 22.5 或更高版本
- 在仓库根目录运行 `npm install`

一键启动
--------

在仓库根目录执行：

  npm install
  npm start

默认地址：

- 抖音前端：http://127.0.0.1:8765/
- 后端 API：http://127.0.0.1:8787/

仓库根脚本会同时启动前端静态服务、同源 API 代理和 ai-corner-renewal 后端。
如果 8787 已有兼容后端，脚本会直接复用；如果默认 8765 被占用，脚本会自动选择
8766 起的空闲端口。请以终端打印的“抖音展示 Demo”地址为准。
显式设置的 WEB_PORT 或 API_PORT 被其他程序占用时，脚本会停止并给出明确提示，
不会擅自改写用户指定的端口。
不要使用 VS Code Live Server 的 5501 端口做联调；它没有本项目需要的 API 和受控媒体代理。

主要体验路径
------------

1. 在抖音首页点击视频右侧的“焕新”，可携带当前视频作为灵感上下文。
2. 进入“AI 一角焕新”，上传空间图片。
3. 等待后端完成解析，检查识别结果并确认封存空间版本。
4. 选择风格、预算和约束，提交设计任务。
5. 等待生成运行完成，查看前后对比、商品建议、执行步骤和校验结果。
6. 在资产与方案页面重新打开已保存的数据。

验证命令
--------

  npm run check:douyin
  npm run check:douyin-integration

check 会执行语法检查和 46 个前端测试。
check:integration 会用隔离的临时数据库完成一次真实的上传、空间封存、任务创建、
运行生成和方案读取闭环，不会写入常用开发数据库。

当前限制
--------

- 当前视频仅作为灵感来源和引用上下文，不会截取视频画面或上传视频文件。
- “调整方案”尚未实现新的修订任务闭环。
- 演示生成器输出的是稳定的本地方案素材，不代表真实模型推理已经接入。
- 尚未补齐鉴权、多用户隔离、部署级监控和生产发布流程。

更完整的架构、对象归属、状态流转、测试与交接信息请阅读 HANDOFF.md。
