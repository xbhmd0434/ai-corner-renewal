# 公开发布检查表

仓库当前默认 Private。完成以下检查后才能切换 Public。

## 代码与秘密

- [ ] `npm run check` 通过。
- [ ] Git 历史中没有访问令牌、Cookie、私钥或真实 `.env`。
- [ ] 前端不包含内部接口地址和不可公开的 Prompt。
- [ ] 所有第三方依赖均有兼容许可证。

## 数据与隐私

- [ ] 没有真实用户空间照片、账号、日志或行为数据。
- [ ] 演示商品明确标记为模拟数据。
- [ ] 演示内容不冒充真实抖音视频或真实达人。
- [ ] 数据来源、更新时间和可用范围有记录。

## 素材与品牌

- [ ] 图片、图标、字体和视频均有明确使用权。
- [ ] 未经授权的 Workshop、达人内容、封面和截图未提交。
- [ ] README 明确说明项目不是抖音官方产品。
- [ ] “抖音”仅用于描述生态适配目标，不构成官方背书。
- [ ] AI 生成素材记录生成方式和用途。

## 产品承诺

- [ ] 效果图明确标记为 AI 示意。
- [ ] 不承诺厘米级测量、硬装设计或专业施工安全。
- [ ] 估算字段包含置信度或复测提示。
- [ ] 真实接口与演示接口在文档和界面中可区分。

## 社区治理

- [ ] `LICENSE`、`CONTRIBUTING.md`、`SECURITY.md` 和行为准则完整。
- [ ] 至少两名维护者可以处理 Issue 和安全报告。
- [ ] `main` 分支保护和 CI 已启用。
- [ ] Issue、PR 模板和首次公开 Roadmap 已准备。

## 发布操作

1. 从干净克隆运行 `npm run check`。
2. 检查 Git 历史，不只检查当前文件。
3. 由三名成员共同确认本检查表。
4. 创建 `v0.1.0` 标签和 GitHub Release。
5. 将仓库可见性从 Private 切换为 Public。
6. 发布后再次检查 README、演示链接和素材加载。
