# AI 一角焕新

把短视频里的家居灵感，适配到我的真实空间。

AI 一角焕新是一个面向年轻租房和家居兴趣用户的空间适配原型。用户选择一段家居灵感、上传自己的书桌照片并补充预算和生活限制，系统生成可预览、可解释、可购买、可执行的一角焕新方案。

> 当前为比赛阶段的交互 MVP。空间识别、商品库存、内容召回和部分方案生成使用公开样例或模拟数据，不代表已经接入抖音内部接口。本项目不是抖音官方产品，也不宣称拥有任何平台私有数据。

## 在线体验范围

当前版本跑通：

```text
选择灵感
→ 上传空间
→ 设置预算与硬约束
→ 模拟 AI Workflow
→ 查看前后效果、商品、步骤、内容与校验
→ 降预算或保存方案
```

主要特性：

- 三组可切换的家居灵感与结构化提取结果
- 本地房间图片预览，不上传服务器
- 预算、租房、保留家具和宠物等约束
- 可解释的模拟 Agent 执行轨迹
- 三套方案、改造前后对比、清单、步骤和可信校验
- “压到 300 元内”的连续调整
- 桌面端和移动端响应式体验

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm run check
npm start
```

打开 `http://127.0.0.1:8765`。

也可以直接打开 [`apps/web/index.html`](apps/web/index.html)，但推荐使用本地服务器以获得一致的浏览器行为。

## 成熟度

- 当前：运行时静态、交互可演示。
- 下一阶段：抖音原生轻交互模式 + 真实空间理解接口。
- 尚未实现：生产级账号、真实内容/商品接口、厘米级测量、持续视频理解、真实交易和硬装施工建议。
